ҮЙ ТАПСЫРМАЛАРЫ — ТҮЗЕТІЛГЕН НҰСҚА

1. ZIP архивін толық шығарыңыз. Ішінен тікелей ашпаңыз.
2. index.html — сайттың басты беті.
3. «Үй тапсырмалары» қалташасын ашып, атыңыз бен рөліңізді таңдаңыз.
4. Мұғалім: сынып ашу → тапсырма беру → «Жариялау».
5. Бір браузердегі оқушы: «Қатысушыны ауыстыру» → оқушы ретінде кіру → сынып коды арқылы қосылу.
6. Басқа құрылғыдағы оқушы: мұғалім «Тапсырмалар мен пікірлерді жүктеу» арқылы JSON береді; оқушы «Файлдан қабылдау» арқылы ашады. Жауап та JSON арқылы қайтарылады.
7. Автоматты ортақ жұмыс: Node.js 24+ орнатып, START-WINDOWS.bat ашыңыз. Мұғалім мен оқушылар бір сервердің мекенжайымен кіреді. localhost тек сол компьютерде ашылады; басқа құрылғылар сервер компьютерінің жергілікті IP мекенжайын қолданады.
8. GitHub Pages тек статикалық нұсқаны ашады. Серверді іске қоспайды. Әртүрлі құрылғы арасында кодпен автоматты байланыс болмайды; JSON алмасуын қолданыңыз.

GitHub-қа ZIP файлын емес, шығарылған барлық файлдар мен қалталарды құрылымын сақтап жүктеңіз. uy-tapsyrmalary қалтасын бөлшектемеңіз. Жаңартқаннан кейін Ctrl+F5 басыңыз.

Түзетулер: тәрбие сағатына сәйкес тапсырмаларды сүзу; мұғалімге тест/сауалнама сұрақтарын көрсету; HTTP жергілікті желіде UUID үйлесімділігі; жаңартылған скрипттерді жүктеу.
