ҰЛЫ ДАЛА КОДЫ + ҮЙ ТАПСЫРМАЛАРЫ
================================

БАСТАУ
1. ZIP архивін толық ашыңыз.
2. index.html файлын ашыңыз.
3. Басты беттегі «Үй тапсырмалары» қалташасын басыңыз.
4. Бөлімнің жоғарғы жағындағы жұмыс режимін оқыңыз.

Екі жұмыс режимі бар.

А. HTML / GITHUB PAGES: ОСЫ ҚҰРЫЛҒЫ РЕЖИМІ
Сервер орнатпай ашылады. Сынып, тапсырма, жауап және пікір осы браузердің
IndexedDB дерекқорына сақталады. Браузер деректерін тазаласаңыз, олар өшеді.
Бұл режим қорғалған аккаунт немесе автоматты онлайн алмасу емес.
Әр құрылғыдағы браузердің дерекқоры бөлек.

Мұғалім:
- Рөл ретінде «Сынып жетекшісі» таңдап, атыңызды енгізіңіз.
- «Сынып қосу» арқылы 1–11 сынып пен параллельді енгізіңіз.
- «34 тәрбие сағаты» бөлімінде өз жоспарыңызды толтырыңыз.
- «Тапсырма беру» арқылы тапсырма жариялаңыз.
- «Тапсырмалар мен пікірлерді жүктеу» батырмасымен тапсырма JSON-ын алыңыз.
  Жалпы тапсырма файлына оқушылардың жеке пікірлері қосылмайды.
- Файлды оқушыға беріңіз.

Оқушы:
- Өз құрылғыңызда «Оқушы» рөлін таңдап кіріңіз.
- «Файлдан қабылдау» арқылы мұғалімнің тапсырма JSON-ын ашыңыз.
- Тапсырманы орындап, «Жұмысты жіберу» батырмасын басыңыз.
- «Менің жауаптарымды жүктеу» арқылы жауап JSON-ын мұғалімге беріңіз.

Тексеру:
- Мұғалім өз сыныбын таңдап, оқушының жауап JSON-ын қабылдайды.
- «Тексеруді күтуде» бөлімінде жұмысты ашады.
- Пікір жазып, қабылдайды немесе толықтыруға қайтарады.
- Тексерілген жұмысты қайта ашып, «Осы оқушыға кері байланысты жүктеу»
  батырмасын басады. Бұл файл сол оқушыға арналған.
- Оқушы кері байланыс файлын қабылдап, қажет болса түзетіп қайта тапсырады.
- Файлмен алмасқанда сол құрылғыдағы бұрынғы қатысушыңызды қолданыңыз.
  Жаңа атпен қайта кіру жаңа қатысушы жасайды.
- Бір JSON файлдың көлемі 60 МБ-тан аспауы керек.

Сынып коды құрылғы режимінде сол браузерде бар сыныпқа қосады.
Басқа құрылғыға тапсырманы жеткізу үшін JSON файлын пайдаланыңыз.

Ә. ОРТАҚ СЕРВЕР: ӘР ҚҰРЫЛҒЫДАН ЖҰМЫС ІСТЕУ
Оқушы жауаптары мұғалімге автоматты түсуі үшін осы режим қажет.
Node.js 24 немесе одан жаңасы керек. Қосымша npm пакеттерін орнату қажет емес.

Windows:
- Node.js 24+ орнатыңыз (https://nodejs.org).
- START-WINDOWS.bat файлын іске қосыңыз.
- Браузерден http://localhost:8080 ашыңыз.
- Ашылған сервер терезесін жауып тастамаңыз.

macOS / Linux / командалық жол:
- ZIP ашылған қалтада: node server.mjs
- Браузер: http://localhost:8080

Мұғалім «Тіркелу» арқылы жеке логин/құпиясөз жасап, рөлін таңдайды.
Сынып ашып, оқушыларға сынып кодын береді.
Оқушы өз аккаунтын тіркеп, кодпен сыныпқа қосылады.
Содан кейін жауаптар, файлдар және пікірлер ортақ серверде сақталады.

Бір жергілікті желіде:
- Оқушылар сервер жұмыс істеп тұрған компьютердің желілік IP-мекенжайын
  қолданады: http://КОМПЬЮТЕРДІҢ_IP_МЕКЕНЖАЙЫ:8080
- localhost мекенжайы әр адамның өз құрылғысына сілтейді. Оны оқушыға
  ортақ сайт мекенжайы ретінде жібермеңіз.
- Компьютер мен оқушылар құрылғылары бір желіде болуы және 8080 портына
  желілік қатынас рұқсат етілуі қажет.

Интернет арқылы:
- Node.js 24+ қолдайтын, тұрақты дискісі бар серверге орналастырыңыз.
- HTTPS пен тұрақты домен баптаңыз. SITE_URL айнымалысына сол HTTPS
  мекенжайын қойыңыз. Қажет болса PORT айнымалысымен портты өзгертіңіз.
- Дерекқор мен файлдарды тұрақты дискіге сақтаңыз; уақытша диск жарамайды.
- GitHub Pages сервер.mjs файлын орындамайды. Онда тек құрылғы режимі
  жұмыс істейді; ортақ аккаунттар мен жауаптардың автоматты алмасуы болмайды.

САҚТАУ
- Сервер деректері: uy-tapsyrmalary/private-data/
- Бұл қалта сервер арқылы ашылмайды және .gitignore арқылы белгіленген.
- Серверді тоқтатып, осы қалтаны толық көшіру арқылы резервтік көшірме алыңыз.
- Оны ашық репозиторийге жүктемеңіз.
- Қалпына келтіру: серверді тоқтату, сақталған қалтаны орнына көшіру, қайта іске қосу.
- Сервер режимінде логин/құпиясөз, сессия және сыныпқа тиесілілік тексеріледі.
- Құрылғы режимінде қатысушылар арасында құпиясөзсіз ауысуға болады.

БАР МҮМКІНДІКТЕР
- 1–11 сыныптар, параллельдер, жеке оқу жылы.
- Әр сыныпқа 34 өңделетін тақырып; JSON жоспар импорты мен алдын ала қарау.
- Сыныпты мұрағаттау, жоспарды келесі жылға көшіру.
- Тапсырманы жоба ретінде сақтау, кейін жариялау.
- Мәтін, эссе, сурет, құжат, аудио/бейне, күнделік, тест, сауалнама.
- Жабық тестті серверде тексеру; бірнеше дұрыс жауапты дәл таңдау ережесі.
- Файл: ең көбі 20 МБ. Бір жауапқа интерфейсте 5 файлға дейін.
- Қабылдау, толықтыруға қайтару, кері байланыс, қайта тапсыру тарихы.
- Оқушы портфолиосы, қатысу есебі, Excel үшін CSV, PDF үшін басып шығару.
- 4 жас тобына 5 үлгіден — 20 үлгі тапсырма. Ресми жоспар емес.

ШЕКТЕУЛЕР
- Бастапқы техникалық тапсырмадағы мектеп әкімшісінің орталық кабинеті,
  мұғалімдерді әкімші бекітуі және мектеп бойынша есеп бұл нұсқада жоқ.
- Қазіргі нұсқада тапсырма таңдалған сыныптың барлық оқушысына беріледі.
- Мұғалімге үлгі файл тіркеу, ашық тест сұрақтарының бөлек бағалау
  конструкторы және серверлік .xlsx/PDF генерациясы қосылмаған.
- Жүктеу барысы көрсетіледі, нақты пайыздық индикатор жоқ.
- Браузерде визуалды тексеру орындалмады. Сервер мен құрылғы режимінің
  негізгі әрекеттері код деңгейіндегі сценарийлермен тексерілді.
- Бұл білім беру модулінің бастапқы нұсқасы; бүкіл мектепке енгізер алдында
  нақты құрылғыларда сынақ өткізіп, аккаунтты қалпына келтіру, резервтік көшіру
  және жүктеме мәселелерін өз ортаңызда реттеңіз.
